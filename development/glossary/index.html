Core lab concepts

TermDefinitionLearn more
Resource GuardCapacity gate that estimates free GPU/CPU/memory and blocks heavy starts when headroom is insufficient. Floor: max(24Gi, 15% allocatable) per node.Resource Guard
headroomFree capacity kept reserved so SSH, K3s, and the dashboard stay responsive under load.Resource Guard, Reboot safety
occupancy vs Guardez-comfy-stack occupancy = Compose project up. This lab gates on K8s requests vs allocatable minus headroom.Resource Guard, Capacity planning
restartPolicyHow Kubernetes restarts Job pods. Heavy inference uses OnFailure or Never with a low backoffLimit (never Always).Reboot safety
manage.shPrimary operator CLI for status, start/stop workloads, SSO, monitoring, and utilities (Bazel: //:manage).Getting started, Shell reference
