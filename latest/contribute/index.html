Setup

  1. Open .devcontainer/ (linux/amd64 + linux/arm64). Guide: Developer environment.
  2. bash .devcontainer/doctor.sh
  3. bazelisk run //:fix then bazelisk run //:validate

Branch from latest development. PR into development. Conventional commits. Never force-push protected branches. Full model: CONTRIBUTING.md.
